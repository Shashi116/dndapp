🎮 GAMEPLAY FLOW:

   STEP 1: DM Setup
   ├─ Go to http://localhost:3000
   ├─ Click "Launch as DM"
   ├─ Wait for DMToolbar to appear
   └─ Note the session ID (shown at bottom)

   STEP 2: Players Join
   ├─ Players go to same URL
   ├─ Click "Launch as Player"
   ├─ Same session ID is used automatically
   └─ Player tokens appear on map

   STEP 3: Start Game
   ├─ DM clicks Brush tool (🖌️ or press "1")
   ├─ DM paints on map to reveal fog
   ├─ Players see updates in real-time
   ├─ Players drag their tokens to move
   └─ Game continues!

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⌨️ KEYBOARD SHORTCUTS (DM Only):

   [1]  - Enable Brush tool (paint fog away)
   [2]  - Enable Rectangle tool (draw rectangles)
   [0]  - Disable current tool
   [R]  - Reset all fog (cover entire map again)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

🎛️ DM TOOLBAR CONTROLS:

   FOG OF WAR Section (Purple):
   ├─ 🖌️  Brush        - Click & drag to reveal fog (smooth brush)
   ├─ 📦 Rectangle     - Drag to draw rectangular reveals
   ├─ ❌ Disable       - Turn off fog tools
   └─ 🔴 Reset Fog    - Restore complete fog coverage

   ENEMIES Section (Orange):
   ├─ Input field      - Type enemy name
   └─ ➕ Spawn Enemy   - Create NPC token on map

   TREASURES Section (Cyan):
   ├─ Input field      - Type item name
   └─ ➕ Spawn Loot    - Place item token on map

   SHORTCUTS Section (Blue):
   └─ Shows keyboard shortcuts

   GUIDE Section (Indigo):
   └─ Quick gameplay tips

🐛 TROUBLESHOOTING:

   Server won't start:
   $ lsof -ti:3000 | xargs kill -9
   $ npm run dev

   CSS/Tailwind not loading:
   $ rm -rf .next
   $ npm run dev

   TypeScript errors:
   $ npm run build

   Socket.io not syncing:
   Check browser DevTools → Network tab → WS connections

📚 TECHNOLOGY STACK:

   Frontend:    Next.js 14 + React 18 + TypeScript
   Styling:     Tailwind CSS v4 (modern directives)
   Graphics:    Konva.js 2D rendering
   Fog System:  HTML5 Canvas with destination-out compositing
   Real-time:   Socket.io 4.7.5
   Backend:     Express.js + Node.js
